# 삼괴 마을 탐험 · 1차 버전

카메라로 등록된 장소를 인식하면 해당 번호의 게임 시작 카드가 뜨고, 터치하면 학생들이 만든 HTML 게임을 실행합니다. 발견 카드는 카메라 화면 위에 고정되며, 3D 물체를 표지석에 붙이는 방식은 아닙니다.

## 사용 순서

1. 태블릿에서 배포된 HTTPS 사이트를 엽니다.
2. **탐색 시작**을 누르고 카메라 사용을 허용합니다.
3. 기준 사진과 비슷한 방향에서 표지석이나 장소를 비춥니다.
4. **N번 마을 → 게임 시작**을 터치합니다.
5. 게임 화면 위 **탐색으로 돌아가기**를 누르면 다시 탐색할 수 있습니다.

카메라 영상은 브라우저 안에서만 처리하며 저장·업로드하지 않습니다. 게임으로 이동하거나 탐색을 종료하거나 다른 앱으로 전환하면 카메라를 끕니다. 돌아오면 탐색 시작을 다시 누릅니다.

## GitHub 저장소와 배포

저장소: https://github.com/able0220/samgoe-village-ar

배포 예정 주소: https://able0220.github.io/samgoe-village-ar/

이 저장소는 GitHub Actions로 배포합니다. `main` 브랜치에 변경 사항을 올리면 `.github/workflows/deploy.yml`이 사이트 파일을 묶어 Pages로 배포합니다. 최초 업로드용 압축 파일은 첫 실행에서 일반 소스 파일과 폴더로 풀어 저장소에 반영합니다.

## 별도 저장소에 수동 배포하기

별도 서버 프로그램, API 키, 설치형 앱, 빌드 과정이 필요 없는 정적 사이트입니다.

1. GitHub 저장소에 **이 폴더의 내용 전체**를 올립니다. 저장소 맨 위에 `index.html`, `assets`, `games`, `vendor` 등이 있어야 합니다. ZIP 파일 자체를 올리는 것이 아닙니다.
2. 저장소의 **Settings → Pages**를 엽니다.
3. **Build and deployment → Source → Deploy from a branch**를 선택합니다.
4. 업로드한 브랜치(일반적으로 `main`)와 **/(root)**를 선택하고 저장합니다.
5. 배포가 완료되면 표시되는 `https://계정.github.io/저장소/` 주소를 학생들에게 안내합니다.

현재 저장소의 배포 방식을 그대로 쓰려면 Pages의 Source를 **GitHub Actions**로 지정하세요. 위 브랜치 방식은 별도 저장소에 정적 파일을 직접 배포할 때의 절차입니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## VS Code에서 확인하기

이 폴더를 VS Code로 열고 로컬 HTTP 미리보기 서버를 사용합니다. `index.html`을 파일 탐색기에서 더블클릭하는 방식은 ES 모듈 및 데이터 로드 제한 때문에 지원하지 않습니다. PC의 `localhost`는 개발용이며, 태블릿에서는 GitHub Pages의 HTTPS 주소를 사용하세요.

## 파일 구성과 번호

- `index.html`, `app.js`, `styles.css`: 시작 화면, 카메라 인식, 발견 카드
- `core.js`: 1~27번 연결 정보 검사
- `game.html`, `game.js`: 해당 HTML을 여는 게임 화면과 탐색 복귀
- `games/1.html`~`27.html`: 제공된 게임을 번호 이름으로 복사한 파일. 내용은 원본과 동일
- `assets/photos/1.jpg`~`27.jpg`: 길이가 긴 변을 최대 1,000픽셀로 줄인 기준 사진
- `assets/villages.json`: 번호, 인식 대상 순서, 게임 경로, 원래 파일명 연결표
- `assets/targets/villages.mind`: 27개 사진의 사전 생성된 인식 데이터
- `assets/target-report.json`: 각 사진의 특징점 수
- `vendor`: 사이트와 함께 제공하는 MindAR 1.2.5 인식 엔진과 라이선스
- `verification.json`: 자동 검증 결과
- `tools`: 사진 교체 후 인식 데이터를 재생성하는 개발용 도구. 일반 배포 시 실행할 필요 없음

연결 기준은 지역명이 아닌 **번호**입니다. 인식 대상 인덱스 0은 1번 게임, 인덱스 26은 27번 게임입니다. 덕다리처럼 사진명과 게임 지역명이 달라도 같은 번호끼리 연결했습니다.

## 확인한 범위와 현장 시험

- 1~27번 사진/게임 연결 및 게임 내용 원본 일치 확인
- 회전 6도, 축소, 명암 변화를 준 27개 기준 사진을 각각 27개 대상 전체와 비교: 모두 해당 번호에만 매칭
- 단색 화면이 어떤 장소로도 매칭되지 않는 것 확인
- 로컬 브라우저에서 1번·27번의 실제 MindAR Controller 이미지 추적 이벤트 확인
- 1번 게임을 열어 퀴즈 응답 및 탐색 화면 복귀 확인
- 기존 게임의 인라인 JavaScript 30개 구문 검사 통과
- 태블릿 세로 화면(768×1024) 시작 화면 배치 확인
- 테스트에 사용한 컴퓨터에서는 카메라 장치를 찾지 못해 실제 카메라 촬영 검증은 미완료

자동 시험은 기준 사진을 변형한 시험입니다. 실제 표지석을 다른 날·다른 각도에서 비춘 현장 인식률을 보장하지 않습니다. 태블릿으로 대표 장소부터 시험하고, 인식이 어려운 곳은 표지석 면 위주로 정면 사진을 다시 준비하는 것이 다음 단계입니다. 사진만 교체하면 인식 데이터가 자동으로 바뀌지 않으므로 재생성해야 합니다.

등록된 사진 자체를 다른 화면에서 비춰도 인식할 수 있습니다. 이 버전에는 실제 방문 인증, GPS 검증, 점수·도장 저장 기능이 없습니다.

인식 데이터는 약 18MB이며 첫 탐색 시 다운로드 시간이 필요합니다. 기존 게임 일부는 외부 글꼴·스타일·스크립트를 사용하므로 인터넷 연결이 필요합니다. 27개 게임의 모든 플레이 단계와 기기별 터치 동작은 별도 검증 대상입니다. 원본 7번 게임은 제공 폴더에 없는 캐릭터 PNG를 참조하지만, 원본에 SVG 대체 표시가 포함되어 있습니다.
